Clinical Risk Model — Live Demo

Interactive demo of the clinical branch from Multimodal Lung Cancer Risk Prediction from Clinical and CT Data — a CatBoost + XGBoost + Logistic Regression ensemble trained on NLST baseline (T0) screening records.
This demo runs the clinical branch only. The manuscript's validated result is a four-branch fusion of this clinical model with three CT-imaging branches (2D CNN, 3D-MIL, and a whole-lung model), which together need image files and model weights far too large to host on a free server. The score below is not the paper's reported fused accuracy — it is meant to let you try the clinical model interactively. Full source code, including the CT branches, is in the GitHub repository.
