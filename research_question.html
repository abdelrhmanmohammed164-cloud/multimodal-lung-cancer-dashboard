Research Question

Can combining clinical data with CT imaging (2D and 3D analysis) produce a lung cancer risk model that outperforms any single data source alone?

This system was built on the National Lung Screening Trial (NLST) cohort (~1,638 patients, T0 baseline visit only). The core hypothesis: a fusion of a clinical-features model, a 2D CT slice-based model, and a 3D CT volumetric model can achieve higher diagnostic accuracy than any one branch working alone — while remaining realistic for actual clinical deployment (a single baseline visit, not multi-timepoint follow-up data).

Methodology constraints

  • T0-only: no post-baseline or follow-up-scan information is used anywhere, even where it might improve numbers — this keeps the model realistic for a patient being screened for the first time.
  • Binary detection, not staging: the target is presence/absence of lung cancer, not tumor stage.
  • Independent, isolated branches: clinical, 2D CT, and 3D CT models are trained and run completely separately, then combined via a validated weighted fusion — not end-to-end joint training.

Success criterion

The fused (clinical + imaging) system must beat the clinical branch alone on the same cross-validated cohort. See Model Performance for the validated result confirming this criterion was met (bootstrap 95% CI entirely above zero).
