BASELINE VISIT

What does "T0" mean?

T0 is the patient's baseline screening visit — their very first CT scan and clinical assessment, before any follow-up. Every feature in this system (all {{ n_features }} clinical fields, plus the CT scan itself) comes only from this single visit. No later follow-up scans, later diagnoses, or growth-over-time information is used anywhere — a real new patient being screened for the first time only ever has T0 data available, so the model is built to work with exactly that, and nothing more.

PIPELINE RULES

How preprocessing works

01

Missing values are imputed using the median from the training cohort (via the saved clinical_imputer.pkl).

02

All columns must be numeric — count/flag columns use 0 = absent, 1 = present; codes (e.g. scr_res0_*) are one-hot flags per your NLST data dictionary.

03

Column order does not matter as long as names match exactly — the pipeline reorders them internally.

04

Do not include pid or has_cancer — those are excluded from the model's inputs.
